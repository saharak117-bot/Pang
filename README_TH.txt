เครื่องเล่นเพลง Android - โปรเจกต์สำหรับสร้าง APK

วิธีสร้าง APK ด้วยโทรศัพท์:
1) แตก ZIP แล้วอัปโหลดไฟล์และโฟลเดอร์ทั้งหมดเข้า GitHub Repository ใหม่ (branch main)
2) เปิดแท็บ Actions และอนุญาตให้ใช้ Actions หาก GitHub ถาม
3) เลือกงาน Build Android APK แล้วกด Run workflow หรือ push ไฟล์ขึ้น branch main
4) รอจนงานสำเร็จ เปิดรายการงาน แล้วดาวน์โหลด Artifact ชื่อ MusicPlayer-debug-apk
5) แตกไฟล์ Artifact จะได้ app-debug.apk แล้วติดตั้งบนโทรศัพท์

ฟีเจอร์ในต้นแบบ:
- สแกนเพลงในเครื่องผ่าน MediaStore
- เล่น/พัก, สุ่ม, วนเพลง
- ปรับ Bass Boost และแหลม (Treble) แยกกันผ่าน Android Audio Effects
- ใช้ Media3 MediaSessionService สำหรับเล่นเบื้องหลัง/แจ้งเตือนควบคุมเพลง
- ทำงานกับไฟล์เพลงในเครื่องโดยไม่ต้องใช้อินเทอร์เน็ตหลังติดตั้ง

ข้อจำกัด:
- ต้องอนุญาตสิทธิ์เข้าถึงเสียงเมื่อเปิดแอปครั้งแรก
- ประสิทธิภาพเอฟเฟกต์เสียงขึ้นกับรุ่นโทรศัพท์และอุปกรณ์เสียง
- โปรเจกต์นี้เป็นต้นแบบ ยังไม่ได้ build/test บนอุปกรณ์จริงในสภาพแวดล้อมนี้
- หาก GitHub Actions แสดง error ให้ส่งภาพหน้าจอหรือ log มาเพื่อแก้ไข
